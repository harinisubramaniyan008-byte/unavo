Don't Waste Food, Share It.

Unavo connects donors, NGOs, volunteers & beneficiaries in one role-based network. All 5 core modules working live - no ML, just pure logic.

📍 Live donor & beneficiary pins • Haversine distance • OpenStreetMap Leaflet

1. Registration & Profile

One table with role field: donor, NGO, volunteer, beneficiary. Name, phone, email, address, lat/long, hashed password. Redirect based on role.

2. Food Listing

Table: donor_id, food_name, quantity, veg/non-veg, expiry, pickup_location, status. Cron flips available → expired after time.

3. Matching (No ML)

Filter available → distance via Haversine / pincode → Sort by soonest expiry + shortest distance → Claim → status = claimed.

4. Location & Routing

lat/long via browser API or Nominatim. Haversine formula for distance. Map shows donor/beneficiary pins.

5. Notification

Table: user_id, message, type, read/unread. Triggers: new food nearby, claimed, expiry 2hr. Polling bell icon.
